\# Projet de Programmation Répartie : Calcul Parallèle \& Ray Tracing



\## Présentation du projet



Dans le cadre de notre projet de programmation répartie, nous avons exploré le calcul parallèle, et plus particulièrement la parallélisation des données. L'application choisie pour cette mise en pratique est le lancer de rayons (ray tracing), un algorithme de synthèse d'images simulant le comportement de la lumière.



Étant donné que le temps de calcul de cet algorithme devient rapidement très lourd avec l'augmentation de la résolution, nous avons conçu et implémenté une architecture distribuée en Java RMI. La solution consiste à découper l'image en plusieurs morceaux, à distribuer les tâches de calcul à différentes machines distantes, puis à assembler leurs résultats pour obtenir l'image finale de manière beaucoup plus rapide.
